# XO-Code Busters

「設計判断を持ち寄る開発研究会 ～XO-Code Busters 奮闘記～」で開発するWebアプリケーションのリポジトリです。

## このプロジェクトについて

このプロジェクトでは、Webアプリケーションを実際に設計・開発しながら、設計や実装における判断について考え、検証し、その過程を記録していきます。

完成した成果物だけではなく、

- なぜその設計にしたのか
- なぜその技術を採用したのか
- 実際に作って何が問題になったのか
- 当初の判断を変更した理由は何か

といった「設計判断の過程」も成果物として扱います。

## 開発方針

特に以下を重視します。

- オブジェクト指向開発
- セキュアコーディング
- 責務の明確化
- テスタビリティ
- 設計判断の記録
- 必要性を確認してから技術を導入すること

フレームワークやライブラリを最初から大量に導入するのではなく、可能な限りシンプルな構成から開始します。

まず標準機能で実装し、実際に生じた課題を確認したうえで、必要に応じて技術の採用を判断します。

## 現在想定している技術構成

### クライアント

- HTML
- CSS
- Vanilla JavaScript
- PixiJS（ゲーム部分で使用予定）

### サーバー

- Debian
- Node.js
- PostgreSQL（導入予定）

### 開発・運用

- Ubuntu
- Visual Studio Code
- Git
- GitHub
- KAGOYA VPS

認証・認可については OAuth 2.0 / OpenID Connect 等を候補として検討します。
